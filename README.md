# SalesPilot AI

SalesPilot AI is a full-stack, multi-agent AI-powered
Sales and Customer Relationship Management (CRM) platform.

## Overview

SalesPilot AI combines a functional CRM platform with
intelligent AI agents to automate sales operations.

## Core Features

- Lead and Contact Management
- Company and Deal Management
- Sales Pipeline Tracking
- AI Lead Qualification
- AI Prospect Research
- Personalized Sales Outreach
- Automated Meeting Scheduling
- Task and Follow-up Management
- Sales Analytics and Reporting
- Multi-Agent Orchestration

## Technology Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS

### Backend
- Django
- Django REST Framework
- PostgreSQL

### AI Service
- FastAPI
- LangGraph
- Large Language Models
- Retrieval-Augmented Generation (RAG)

### Infrastructure
- Docker
- Redis
- Celery

## Project Structure

- apps/web: Frontend application
- apps/crm-backend: Django CRM backend
- apps/ai-service: Multi-agent AI service
- packages: Shared contracts
- infrastructure: Deployment configuration
- docs: Technical documentation
- tests: Integration and end-to-end tests
